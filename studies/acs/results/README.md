# Сохранённые результаты

`tables/` и `figures/` содержат проверенные сводные результаты завершённого запуска
`oks_no_crp_indicator_v2_d138be90f9f1`. Они перенесены из исходной папки ОКС;
переорганизация репозитория не является новым обучением моделей.

Основная оценка качества: `tables/02_сравнение_моделей.csv`, средние трёх полных
внешних OOF-повторений. `02_метрики_блоков.csv` содержит метрики девяти отдельных
внешних блоков. Эти способы агрегирования различаются, особенно для AP.

`archive/before_crp_indicator_removal/` — явно исторические сводки прежнего запуска
с отдельным индикатором пропуска СРБ. Это не результаты текущей конфигурации.
При смене семейства модели и шкалы SHAP абсолютные величины вкладов несопоставимы.

Полные OOF, разбиения, индивидуальные SHAP, базы поиска и модели сохранены только
локально в `../artifacts/private/reference/`. Проверить их можно командой
`python scripts/validate_results.py --run reference` из корня.
Новые вычисления идут в другой каталог `../artifacts/private/runs/current/` и не
перезаписывают эти публичные сводки автоматически.

Здесь нет waterfall отдельных пациентов, beeswarm с индивидуальными точками,
точечных диаграмм клинических записей и извлечённых текстов отчётов.
Синтетические иллюстрации с принудительно заданными средними/CV не включены в
эмпирические результаты. Их исходный код отдельно обозначен в `../examples/`.
